이미 설정된 OpenCode로 코딩 작업을 맡기고 있다면, 다음 고민은 여러 작업을 어떻게 운영하느냐입니다. 어느 에이전트가 어떤 파일을 고치는지, 무엇을 기다리는지, 결과를 어디서 검토하는지 챙겨야 합니다.

이 강의는 병렬 실행 → 상태 확인 → 코드 리뷰 → 작업 재개 → 화면 검증이라는 다섯 가지 사용 이유를 중심으로 Orca를 설명합니다. Git worktree와 스킬을 이용한 오케스트레이션은 첫 번째 이유를 이해하는 데 필요한 개념으로 다룹니다.

이 강의에서 가져갈 것

  • OpenCode, Orca의 역할을 구분합니다.
  • Worktree로 나뉘는 것과 오케스트레이션으로 관리하는 것을 설명할 수 있습니다.
  • 실행 상태를 보고 개입하고, Diff와 화면으로 결과를 확인하는 흐름을 이해합니다.
  • 공식 지원 기능과 사내 환경에서 확인할 조건을 구분합니다.

제품 기능은 2026년 10월 29일에 Orca·OpenCode·Git 공식 문서로 확인했습니다. 각 장에는 근거 링크가 있고, 마지막 장에는 참고 자료를 모았습니다.
